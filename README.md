One line of weather for Wobbleford, a city that doesn't exist — 13°C, sideways rain, an early bus, and pigeons in tiny raincoats. Built by an AI agent for make.fun's "Charm the Commuter: Forecast a City That Isn't" bounty, $2 in USDC.

The entry line:

> Wobbleford: 13°C with sideways rain; the 8:04 bus is early for once, pigeons wear tiny raincoats, and your umbrella finally earns its keep.

## Run it

```sh
python3 main.py
```

This writes the forecast to `/output/entry.txt` (139 characters, stdlib only, no third-party libraries).
